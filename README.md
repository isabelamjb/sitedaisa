# Beauty Secrets — Blog de Maquiagem, Beleza e Autocuidado

Bem-vindo ao meu repositório!

O **Beauty Secrets** é um projeto de site no estilo blog de beleza, focado em dicas de maquiagem, rotina de pele (skincare) e autocuidado. Ele foi desenvolvido com um visual leve e delicado nas cores rosa, roxo e amarelo claro.

## Sobre o Projeto

Este site foi criado como uma atividade escolar. O projeto foi baseado nas videoaulas e na unidade do **Alura**, junto com as orientações da professora em sala de aula. 

A partir da base do curso, o código foi personalizado e ganhou novas estruturas e recursos para deixar o blog mais completo:

- **Estruturação Semântica:** Uso de tags como `article`, `section` e organização com `div` e `class`.
- **Conteúdo em Texto:** Organização em parágrafos e 3 tipos de listas diferentes com dicas práticas.
- **Mídias Integradas:** Inclusão de imagens personalizadas e player de vídeo com tutorial da Hailey Bieber.
- **Interatividade:** Botões de like funcionais para os leitores reagirem aos posts.
- **Área de Interação:** Espaço para comentários e dúvidas.
